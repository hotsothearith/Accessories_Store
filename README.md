# 🛍️ Accessories Store Website (Frontend Only)

This is a **frontend-only e-commerce website** for showcasing various accessories like phone cases, chargers, and more. The site is fully built with HTML, CSS, and JavaScript, with a clean and responsive layout. It is designed as the foundation for a future full-stack e-commerce platform.

## 💡 Features

- 🖼️ Product display with images and descriptions
- 📱 Responsive design for desktop, tablet, and mobile
- 🔍 Simple and clean UI using custom CSS
- 🔗 Navigation bar with multiple pages (Home, Product, Contact, etc.)
- 📨 Contact form (not functional yet – needs backend)
- 🎨 Hover and transition effects

---

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and layout
- **JavaScript** – UI behavior (e.g., navigation toggles)
- **Google Fonts** – Custom font styles
